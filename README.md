# Retail & Marketing Analytics Dashboard

## Project Overview
This project focuses on customer segmentation, revenue analysis, and business intelligence using real-world e-commerce data.

The goal was to analyze customer purchasing behavior, identify high-value customers, and generate actionable business insights using data analytics and machine learning techniques.

---

## Key Features
- End-to-end analytics workflow
- SQL-based business analysis
- KPI engineering
- Revenue trend analysis
- RFM customer segmentation
- KMeans clustering
- Interactive Power BI dashboards
- Executive business insights

---

## Tech Stack
- Python
- Pandas
- SQL (SQLite)
- Power BI
- Scikit-learn
- Streamlit

---

## Business Problems Solved
- Identified VIP and at-risk customers
- Analyzed regional revenue concentration
- Measured customer purchase behavior
- Built executive-level KPI dashboards
- Generated customer retention insights
